- 2026-10-16 — Phase 3 (PROMPT-001): rewrote the fixed Persian proofreading system prompt in `backend/app/services/prompt.py`. The instructions are now English while the corrected text stays Persian, and they state six rules: (1) context-aware typo correction using the surrounding context, with «سلا» → «سلام» as the example and no guessing when the intended word is genuinely ambiguous; (2) register preservation — formal stays formal, colloquial stays colloquial, and «می‌خوام» must never be rewritten as «می‌خواهم»; (3) systematic proofreading of spelling, grammar, word boundaries, Persian half-spaces (نیم‌فاصله, ZWNJ), spacing, punctuation, and typography; (4) punctuation added or corrected from context, including questions written without any punctuation; (5) meaning preservation — no invented meaning, added information, summarizing, or rewriting, and the least invasive correction when punctuation or word separation is ambiguous; (6) output format — corrected Persian text only, meaningful line breaks kept, no explanations or quotation marks, and unchanged text when nothing needs fixing. No provider, service, endpoint, schema, or configuration code changed.
